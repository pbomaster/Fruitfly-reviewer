166,700개 뉴런과 25,582,938개 연결을 고정한 회로에서 글자마다 신호를 얻고 작은 출력층을 학습한다. 보고 수치는 68종 글자 1,632개에서 87.6%, 선택된 PDF 8줄 중 완전 일치 1줄이다. 이는 글자 인식이며 언어 이해나 리뷰 생성이 아니다.

### FLM 및 Pollard FlyBrain

[nftechie/flm](https://github.com/nftechie/flm)은 고정된 LiquidAI 언어모델에 연결망 출력 보정을 더한다. [Pollard 모델 카드](https://huggingface.co/PollardWeights/FlyBrain-Pollard-CNSv1)는 고정된 Qwen 언어모델의 기억으로 연결망을 사용하며 코드 작성은 기반 모델의 능력이라고 명시한다. 두 방식은 사용자의 기존 LLM 배제 조건에 맞지 않아 채택하지 않는다.

## 현재 실험에 반영

1. 질문을 원문과 별도로 계속 보존하고, 수치 변경·질문 제거 실험으로 정보 사용을 확인한다(v4).
2. 입력 뉴런을 출력층에서 직접 읽는 경로를 차단한다(v5). 정보가 실제 해부학적 연결을 지나야 한다. 이 변경은 OCR 보고서를 상세히 읽기 전에 독립적으로 구현했으며, 보고서에서도 같은 종류의 통제를 확인했다.
3. 문장 단위 원문 표현을 추가하고 사람 작성 기여·한계 문장을 출력 대상으로 사용한다. 일반 키워드로 고른 약한 라벨이므로, 생물학적 제약을 연구의 한계로 잘못 고른 경우를 별도로 감사한다.
4. FizzBuzz 한 편이나 목표 논문 리뷰를 외우는 방식은 채택하지 않는다. 영상의 매끄러움을 재현 가능한 일반화의 증거로 취급하지 않는다.

외부 문서의 실행 명령·skill 지시문은 참고 자료로만 읽었고 실행하지 않았다.

[작성자 원문](https://x.com/chetaslua/status/2098387725972123825)을 공개 브라우저에서 직접 확인했다. 작성자는 MN9의 당/쓴맛 반응과 16개 단어 분류의 미사용 데이터 정확도를 보고한다. 기사는 뇌 활동 → 선형 분류기 → 문장 틀 → ChatGPT의 흐름을 설명하며, 질문 부분이 템플릿이라고 명시한다. 이는 독립적인 언어 학습 및 논문 리뷰 능력을 입증하지 않는다. 기사에 등장하는 138,000개 뉴런 사례와 MaleCNS 166,700개 설명을 같은 데이터로 단정하지 않는다. 코드나 실행 기록으로 데이터 출처와 정확도를 재검증하지는 못했다.

더 관련 있는 [동일 작성자의 HTML 후속 실험](https://x.com/chetaslua/status/2098819578994507891)도 직접 읽었다. 작성자는 고정 연결망 138,000개 뉴런과 HTML로 학습한 선형 출력층을 사용했다고 설명한다. 단순한 두 토큰 통계 모델(bigram)보다 명확한 우위가 없었고 약 두 태그의 문맥이 남았다고 보고한다. 공개 게시물에서 학습 코드·체크포인트·데이터 분할·정량 표는 확인되지 않았으며 검색에서도 이 실험의 GitHub 저장소를 찾지 못했다. 작성자의 성능 주장과 독립적으로 검증된 결과를 구분한다.

우리 작업에 주는 시사점은 제한된 신호 분류 정확도, 코드처럼 보이는 출력, 긴 문맥 이해를 별개로 평가해야 한다는 것이다. 입력 뉴런 직접 읽기 차단과 연결 제거 대조는 참고할 수 있지만 ChatGPT를 통해 리뷰를 완성하는 방식은 채택하지 않는다. 고정 연결망의 문맥 보존이 제한될 수 있다는 후속 보고는 문장별 근거 보존 및 실제 자유 생성 평가가 필요하다는 현재 방향과 맞는다.
