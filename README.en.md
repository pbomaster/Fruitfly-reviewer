# Fruitfly-reviewer

[한국어](README.md) | [English](README.en.md)

**An experimental paper-extraction model trained using the MaleCNS fruit fly connectome.** It uses no pretrained large language model weights or LLM API. It selects contribution and limitation sentences from a PDF to produce a short paragraph.

This is a limited extractive result, not a general scientific peer reviewer.

## Actual output and scope

The final model's **unedited output**, generated by reading the 39-page paper directly from its PDF:

> We present the connectome of the entire Drosophila male central nervous system. Limitations due to lack of hemilineage assignment, ambiguity in lineage/cell type delineation, and technical limitations imposed by the genetic labeling prevented annotation for certain groups of cells.

[Raw output](outputs/review-runs/final-v9-fallback/review.txt) · [Evaluation](outputs/sections-v9/evaluation.json) · [Training log](outputs/sections-v9/training.jsonl)

The source is Berg et al., *Sexual dimorphism in the complete Drosophila male central nervous system connectome*, [DOI: 10.1016/j.cell.2026.08.015](https://doi.org/10.1016/j.cell.2026.08.015). The first sentence extracts the contribution of constructing the entire male CNS connectome; the second extracts a real limitation. The second sentence's original context concerns **fruitless/doublesex expression annotation** in particular. It does not mean that all cell-type annotation was impossible.

| Evaluation | Result |
|---|---|
| 32 extraction examples from 10 held-out papers | Exact match of both sentences: 15/32 (46.875%) |
| Normal termination | 32/32 |
| Connectome signal removed | No exact matches; empty outputs |
| Training on the target PDF | None; training papers dated through 2022 |
| Counterfactual number changes | Failed to output the four changed numbers; selected another contribution sentence |

**Limitations:** The model does not write original criticism. Evaluation is small, output retains the authors' voice, sentence selection varies with PDF extraction, and figures are not interpreted. Removing the graph does not establish that anatomical wiring outperforms random wiring. Success on the target PDF does not establish general reviewing ability.

## Architecture

- A sparse recurrent network uses **49,393 neurons and 9,050,172 connections** from the MaleCNS central brain. It is not a biological simulation of all 166,700 neurons.
- Only connectivity, connection weights, and input-neuron indices are read from the upstream artifact. Its language weights are not loaded.
- Embeddings, input transformations, and output pathways trained in this project are combined with source-copy memory, coverage tracking, and abstract/body markers. These external memory and learned components also contribute to the result.
- After the public model produced unrelated stories and a small output-layer training experiment overfit, the project changed its scientific training material and context-processing architecture. An AI-written target review was not substituted for model output.

## Run — Windows 11 / RTX 5090

Validated environment: Python 3.12.14, NVIDIA driver 616.92, PyTorch 2.7.1+cu128, CUDA 12.8, RTX 5090 with 32 GB VRAM. Other environments have not been verified. Run from the repository root:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe check_gpu.py
.venv\Scripts\python.exe download_graph.py
.venv\Scripts\python.exe work/generate_review.py --pdf "C:\path\to\paper.pdf"
```

The final checkpoint (approximately 61 MB), project-trained tokenizer, and word-frequency table are included. The upstream graph artifact (approximately 284 MB) is downloaded separately at a pinned revision and checked with SHA-256. Supply your own PDF.

New results are saved under `outputs/review-runs/<timestamp>/`. `review.txt` contains the unedited model output. Extracted pages, normalization records, generated tokens, and run metadata are also saved. **These folders contain the paper's full extracted text and local paths, so they are excluded from Git by default.** If pypdf cannot read the target PDF, the runner retries with PyMuPDF.

## Training history and reproducibility

Training material was prepared from public eLife XML, preserving paper-level splits and excluding papers after 2022. Development progressed through language training within this project, scientific text, query and source-copy memory, sentence transitions, coverage tracking, and abstract/body markers. Final v9 training used a refined set of 251 training, 12 validation, and 11 test papers for 500 steps. The step-250 checkpoint was selected using the validation objective.

This release is organized to **reproduce inference with the final model**. Historical training and evaluation code is retained under `work/`, but earlier checkpoints and large corpora are not included. It is not a package that reproduces all training from scratch with a single command. See [experiment history and reproducibility constraints](docs/EXPERIMENTS.md), currently in Korean.

Training checkpoints store model, optimizer, and random states in two slots, allowing fallback to an older slot after corruption. During training, request a checkpoint and pause with `work/control_training.py pause --run sections-v9`, then use `status` to confirm that the process has stopped. The distributed final weights are for inference and contain no optimizer state. The historical training tools retain a four-hour run limit and a pause window of 09:25–19:30 Korea time.
