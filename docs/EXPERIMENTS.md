# 실험 경과와 재현 제약

## 진행 순서

1. 공개 모델은 초록·전체 PDF 모두 무관한 동화를 생성했다. 리뷰 20편으로 출력층만 추가 학습한 시도도 과적합으로 실패했다.
2. 자체 초기화한 언어 구성요소와 연결망을 사용하고, 숫자·질의 복사 과제로 기본 입력 추종을 점검했다(v2).
3. eLife 과학 문헌을 사용해 문맥을 바꾸었다(v3). 질의와 원문 복사 메모리를 추가했다(v4–v5).
4. 문장 이동, 전환 시점 손실 가중치, 이미 사용한 원문 위치 기록을 도입했다(v6–v8).
5. 더 구체적인 한계 문장과 초록/본문 표시, 최대 24문장 후보로 학습했다(v9). 최종 가중치는 v8에서 이어 학습했다.

목표 논문 자체나 목표 리뷰를 학습하지 않았다. 초기 과학 코퍼스는 학습 1,320편 / 검증 73편 / 시험 74편으로 분할했고, 이후 발췌 자료를 정제하면서 최종 v9 자료는 251/12/11편으로 줄었다. 실제 평가 32예제는 이 시험 분할 중 10편을 포함한다. 서로 다른 단계의 논문 수와 평가 예제 수를 혼동하지 않아야 한다.

## 자료·코드

- `fetch_elife.py`: 출판사 XML 다운로드. 배포 사본은 실험에서 기록한 `0c5058c62b6b4985c9fa0ac3c773ba8107350a2e` 리비전으로 고정했다. 다운로드 콘텐츠를 실행하지 않는다.
- `prepare_elife.py`: 자료 선별, 논문별 분할, 자체 토크나이저.
- `prepare_extractive.py`, `refine_limitations.py`, `prepare_section_corpus.py`: 발췌 자료와 한계 문장 정제.
- `train_pointer.py`부터 `train_sections.py`까지: 여러 단계의 역사적 학습 코드. 단계별 초기화 체크포인트가 필요하다.
- `generate_review.py`: 동결된 최종 체크포인트로 PDF부터 생성하는 실행 경로.

학습 전체 재현에는 원본 자료 다운로드·전처리, 각 단계 실행과 중간 가중치가 필요하다. 이번 배포에서는 이 전체 과정을 깨끗한 환경에서 다시 수행하지 않았다. 역사적 감사 도구 일부는 로컬 원본 작업공간에만 있는 입력 파일에 의존한다. 최종 추론과 전체 학습 재현을 구분한다.

## 결과 해석

최종 PDF 실행은 주요 기여와 제한 사항을 발췌했으나, 구체적 수치를 포함하지 않았다. 별도 캐시 텍스트 실행은 8,069 / 138 / 289 / 71개 유형을 포함한 문장을 골랐다. `outputs/sections-v9/normalized-paper-raw.txt`는 그때의 띄어쓰기 오류까지 보존한다. 추출기가 다르면 선택 문장도 달라졌다.

숫자를 바꾼 입력은 변경된 네 숫자를 출력하지 못했다. 연결 제거 시 빈 출력은 모델이 연결망 신호에 의존함을 보여 주지만 해부학적 구조의 우월성을 입증하지 않는다. 무작위 배선, 크기와 학습량을 맞춘 일반 재귀망, 더 많은 미사용 논문으로 평가하는 것이 후속 과제다.

GPU 희소 연산·입력 경사와 전체 그래프 GPU/CPU 수치 비교를 통과했다. 중단 후 재개 및 체크포인트 손상 복구도 검사했으나 실제 전원 차단 실험은 하지 않았다.

## 외부 데모 조사

[조사 기록](../outputs/FLYTHON-RESEARCH.md)은 Python 코딩 영상과 ChatGPT 연결 기사, 비교 가능한 공개 구현을 구분한다. 영상만으로 학습·일반화·기존 LLM 미사용을 입증하지 않는다. 이 외부 코드나 출력을 최종 모델 출력으로 사용하지 않았다.
